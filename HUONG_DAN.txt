2. Mo repository GitHub dang chua website.
3. Tai len cac file HTML va style.css o ngay thu muc goc (repository root).
4. Tai len ca thu muc images (phai giu nguyen ten file va ten thu muc).
5. Commit changes, doi 1-2 phut roi tai lai trang GitHub Pages.
